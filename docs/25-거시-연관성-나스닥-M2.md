# 25. 거시 연관성 — 나스닥·M2 와 비트코인 (실제 데이터)

2026-07-31. "나스닥·전 세계 M2 와 비트코인의 연관성을 실제 데이터로 분석하고,
M2 는 전 세계인지 특정국인지 보자"는 요청을 **실측**으로 실행한 기록이다.

```bash
python3 tools/fetch_macro.py --github --global               # 실제 데이터 받기
python3 tools/macro_correlation.py --macro data/macro.csv    # 분석
python3 tools/macro_correlation.py --self-test              # 로직 검증
```

---

## 1. 데이터 — 이 환경에서 실제로 받았다

두 소스를 합쳐 받는다. **FRED**(미국 연준)에서 실제 나스닥과 각국 광의통화를,
**GitHub 공개 데이터셋**에서 주식·VIX 를 받는다.

| 열 | 출처 | 주기·범위 |
|---|---|---|
| `nasdaq` | FRED **NASDAQCOM** | 일간, 1971~2026-07 (**실제 나스닥 종합**) |
| `sp500` | datahub s-and-p-500 | 월간, ~2026-06 |
| `vix` | datahub finance-vix | 일간, ~2026-07 |
| `m2_us`·`m2_jp`·`m2_gb`·`m2_eu`·`m2_cn` | FRED **MABMM301**(OECD 광의통화) | 월간, ~2023-11 (중국은 ~2018-12) |
| `m2_global` | 위 US+JP+GB+EU 합(USD 환산) | 월간, ~2023-11 |

**두 개의 함정을 넘었다.** (1) FRED 를 `User-Agent: btc-core/1.0` 로 부르면 앞단
WAF 가 본문 전송을 멈춰 세워 urllib 이 타임아웃난다(같은 URL 을 curl 로는 0.6초에
받음). 표준 UA(`curl/8.0`)로 고쳤다. (2) 국가별 M2 는 정의를 맞춰야 "전 세계 vs
특정국" 비교가 성립한다 — 예전 MYAGM2* 시리즈는 FRED 가 중국·영국 것을 폐기했으므로,
US·JP·GB·EU·CN 이 모두 살아 있는 **OECD 광의통화(MABMM301)** 로 통일했다.

## 2. 무엇을 재는가 — 레벨이 아니라 변화율

세 시계열(주식·M2·비트코인)은 전부 장기 우상향이다. **레벨끼리 상관을 재면
"같이 올랐다"만 나온다** — 허위 상관이다. 그래서 전부 변화율로 잰다.

- **주식** — 로그수익률 상관(나스닥 일간→주간, S&P500 월간).
- **VIX** — BTC 월수익률 vs ΔVIX. 위험자산이면 공포 커질 때 빠진다(음의 상관).
- **M2** — 전년비 증가율의 **선행/후행 스캔**(0~12개월). BTC 수익률을 M2 증가율보다
  k개월 뒤로 놓고 상관이 최대가 되는 k = "M2 가 BTC 를 k개월 앞선다."

로직은 합성 데이터로 못 박았다 — 심은 3개월 선행·VIX 음의 관계를 도구가 되찾는다
([tests/test_macro.py], `--self-test`).

## 3. 실측 결과

### 나스닥 ↔ 비트코인 (주간 수익률, 837주 2010~2026)

| 구간 | ρ |
|---|---|
| 전 구간 | +0.13 |
| 2013~2019 | **+0.02** (거의 무상관) |
| 2020~현재 | **+0.34** |
| 최근 26주 | **+0.56** |

**국면 전환이 뚜렷하다.** 2020년 이전엔 사실상 무상관(비트코인은 크립토 고유
사이클), 2020년 기관 편입·거시 유동성 국면부터 "고베타 위험자산"으로 붙기 시작해
최근엔 +0.56 까지 올랐다. (S&P500 월간도 같은 이야기: 전 구간 +0.22, 2020후 +0.30.)

### VIX ↔ 비트코인 (192개월)

전 구간 ρ **−0.19**, 2013~19 −0.10 → 2020~현재 **−0.34**. 음수 = 공포 커질 때
BTC 하락. 나스닥 결과를 **반대 부호로 확증** — 2020년 후 위험자산성이 깊어졌다.

### M2 ↔ 비트코인 — 전년비, 선행/후행 스캔 (핵심: 전 세계 vs 특정국)

| 시리즈 | 동시 ρ | 최적 선행 | 그때 ρ |
|---|---|---|---|
| **m2_cn (중국)** | +0.15 | **9개월** | **+0.45** |
| m2_global (US+JP+GB+EU) | +0.14 | 1개월 | +0.16 |
| m2_us (미국) | +0.04 | 0개월 | +0.04 |
| m2_jp (일본) | −0.05 | — | 음수 |
| m2_eu (유로) | −0.24 | — | 음수 |
| m2_gb (영국) | −0.13 | (경계) | 잡음 |

**답: 전 세계 집계보다 "특정국 = 중국"이 압도적으로 잘 맞는다.**

- **중국 M2 증가율이 BTC 를 8~9개월 앞서며 ρ +0.45.** 선행 곡선이 0→9개월까지
  단조 상승했다 꺾인다(뚜렷한 언덕) — 통화 풀리면 위험자산이 나중에 따라 오른다는
  가설에 부합하는, 이 데이터에서 **유일하게 뚜렷한 선행 관계**다.
- **미국 단독은 사실상 0(+0.04), 선행 없음.** 일본·유로는 오히려 음수. 즉
  **"미국 M2 가 BTC 를 끌어올린다"는 실측에서 성립하지 않는다.**
- **전 세계 집계(US+JP+GB+EU)는 약한 양(+0.16, 1~2개월 선행)** — 미국 단독보단
  낫지만 중국 근처도 못 간다.

> **함의:** 대중적 "전 세계 M2 가 BTC 를 10~13주 앞선다"는 오버레이 차트는, 실측으로
> 뜯어 보면 대체로 **① 중국 유동성(2018 이전)** 과 **② 2020~21 유동성 급증 한 번**이
> 끌어올린 것이다. 미국·유럽·일본 M2 자체엔 그런 선행이 없다.

**꼭 짚을 한계.** (a) 중국 광의통화가 FRED 에서 **2018-12 에 끊겨**, 그 +0.45 는
**2010~2018 관계**다(코로나 이후는 이 데이터로 확인 못 함). (b) 통화 사이클 표본이
두세 번뿐이라 표본 외 안정성은 약하다. (c) 개별국은 자국통화 YoY, 집계는 USD 환산 합.

## 4. 그래서 시스템에 어떻게 반영하나

**실측이 한 방향을 가리킨다: 거시 결합은 실재하나 완만·국면 의존적이고, 유일하게
뚜렷한 M2 선행조차 한 나라(중국)·한 시기(2018 이전)에 몰려 있다.** 이건 이미 있는
설계를 정면으로 뒷받침한다 — 거시는 BCS 점수(방향)에 넣지 않고, **LRS(유동성 레짐
축)** 의 크기 조절(0.75~1.25배)에만 쓴다([config/strategy.yaml] `lrs.components` 의
`global_m2_yoy`·`dxy`). "순풍일 때 조금 더, 역풍일 때 조금 덜"이지 방향 신호가 아니다.

M2 를 방향 신호로 쓰면 안 되는 이유가 실측으로 분명하다 — 미국·유럽·일본은 관계가
없거나 반대고, 유일한 선행(중국)마저 데이터가 2018 에서 끊긴다. `global_m2_yoy` 는
지금 `manual` 입력이라, `fetch_macro.py` 가 그 값을 자동으로 채우도록 잇는 것이 다음 단계다.
