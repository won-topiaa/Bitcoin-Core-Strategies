# 25. 거시 연관성 — 주식·M2 와 비트코인 (실제 데이터)

2026-07-31. "나스닥·전 세계 M2 와 비트코인의 연관성을 실제 데이터로 분석하고,
M2 는 전 세계인지 특정국인지 보자"는 요청을 **실측**으로 실행한 기록이다.

```bash
python3 tools/fetch_macro.py --github                        # 실제 데이터 받기
python3 tools/macro_correlation.py --macro data/macro.csv    # 분석
python3 tools/macro_correlation.py --self-test              # 로직 검증
```

---

## 1. 데이터 — 이 환경에서 실제로 받았다

거시의 표준 무료 출처는 **FRED**(미국 연준)지만, **이 에이전트 프록시가
fred.stlouisfed.org 를 정책상 403 으로 막는다**(Yahoo·Stooq 도 같다). 대신
**raw.githubusercontent.com 은 열려 있어서**, GitHub 공개 데이터셋으로 실제
숫자를 받았다:

| 열 | 출처 | 주기·범위 |
|---|---|---|
| `sp500` | datahub `s-and-p-500` | 월간, ~2026-06 |
| `vix` | datahub `finance-vix` | 일간, ~2026-07 |
| `m2_us` | FRED **M2SL** 미러 | 월간, 2000~2025-03 |

M2 미러 값은 FRED M2SL 원 수준과 일치함을 확인했다(2025-02 ≈ 21670 = 약
$21.7조). **나스닥 종합**의 깔끔한 최신 무료 CSV 는 못 찾았는데, 월간 수익률
수준에서 나스닥과 S&P500 은 사실상 같이 움직이므로(둘 다 광의 미국 주식)
S&P500 을 대용으로 쓴다 — 이 분석의 결론(주식-위험자산 커플링)은 둘 사이에서
바뀌지 않는다. **전 세계·개별국 M2 집계**는 GitHub 에 깔끔한 공개 CSV 가 없어,
그건 FRED 가 열린 환경에서 `fetch_macro.py --global` 로 받는다(도구는 완성돼 있다).

## 2. 무엇을 재는가 — 레벨이 아니라 변화율

세 시계열(주식·M2·비트코인)은 전부 장기 우상향이다. **레벨끼리 상관을 재면
"같이 올랐다"만 나온다** — 허위 상관이다. 그래서 전부 변화율로 잰다.

- **주식(S&P500)** — 월간 로그수익률의 상관. "요즘 얼마나 같이 움직이나."
- **VIX(공포지수)** — BTC 월수익률 vs **ΔVIX**. 위험자산이면 공포가 커질 때 빠진다(음의 상관).
- **M2** — 전년비 증가율의 **선행/후행 스캔.** BTC 수익률을 M2 증가율보다
  k개월 뒤로 놓고 상관이 최대가 되는 k 를 찾는다 = "M2 가 BTC 를 k개월 앞선다."

로직은 합성 데이터로 못 박았다 — M2 를 BTC 보다 **정확히 3개월 앞서게** 심으면
스캔이 3개월을, VIX 음의 관계를 심으면 음의 상관을 되찾는다([tests/test_macro.py]).

## 3. 실측 결과

### 주식(S&P500) ↔ 비트코인 — 월간 수익률, 191개월(2010-08~2026-06)

| 구간 | ρ | n |
|---|---|---|
| **전 구간** | **+0.22** | 191개월 |
| 2013~2019 | +0.22 | 84개월 |
| 2020~현재 | **+0.30** | 78개월 |
| 최근 24개월 | +0.19 | — |

- **양의 상관이지만 완만하다.** 사람들이 흔히 인용하는 0.4~0.6 은 **일간**
  위험선호(risk-on/off) 스파이크다. 월간으로 내려오면 +0.2~0.3 수준 — 진짜
  결합은 생각보다 약하다.
- **2020년 이후 강해졌다**(+0.22 → +0.30). 기관 편입·거시 유동성 국면에서
  비트코인이 "고베타 위험자산"으로 취급된 결과다.
- **연도별은 국면 의존적이다.** 크립토 고유 사이클(2017 −0.04, 2018 −0.20,
  2019 −0.32, 2023 −0.29)엔 오히려 벌어지고, 거시 유동성 해(2020 +0.64,
  2024 +0.68)엔 붙는다. **고정 상수가 아니다.**

### VIX(공포지수) ↔ 비트코인 — 192개월

| 구간 | ρ |
|---|---|
| **전 구간** | **−0.19** |
| 2013~2019 | −0.10 |
| 2020~현재 | **−0.34** |

주식 결과와 **같은 이야기를 반대 부호로** 확인해 준다. 음수 = 공포가 커질 때
BTC 하락 = 위험자산. 그리고 2020년 이후 **더 깊어졌다**(−0.10 → −0.34) —
비트코인이 갈수록 위험자산처럼 거래된다.

### 미국 M2 ↔ 비트코인 — 전년비 증가율, 선행/후행

| 선행(개월) | 0 | 1 | 2 | 3 | 4 | 5 | 6 |
|---|---|---|---|---|---|---|---|
| ρ | **+0.06** | +0.04 | +0.02 | +0.01 | +0.00 | −0.01 | −0.01 |

**놀라운 결과 — 대중적 "M2 가 BTC 를 앞선다" 서사가 실측에서 깨진다.**

- **상관이 사실상 0(+0.06)이고, 선행 구조가 없다** — 상관이 lag 0 에서 가장
  크고 뒤로 갈수록 줄기만 한다. 미국 M2 가 BTC 를 앞선다는 증거가 없다.
- **왜 0 인가**(연도별 M2 YoY vs BTC YoY 를 뜯어보면):
  - 2020~21: M2 +26%, BTC +800% — 같이 급등(양).
  - 2022: 둘 다 급락(양).
  - **2023: M2 는 −4%로 계속 수축**(역사상 첫 M2 감소)**했는데 BTC 는 −40%
    → +155% 로 급반등**(음). 이 한 해가 앞의 양을 상쇄한다.
- 즉 "통화 풀리면 BTC 오른다"는 2020~21 **한 번**의 동반 급등에 기댄 것이고,
  2023 처럼 **M2 가 줄어도 BTC 가 오르는** 반례가 관계를 지운다.

> **참고:** 유명한 오버레이 차트(전 세계 M2 를 10~13주 앞당겨 BTC *가격*에 겹침)는
> (a) 미국이 아니라 **전 세계** M2 이고, (b) 변화율이 아니라 **레벨·가격**을
> 겹치는 방식이라 우상향-추세 허위상관이 섞인다. 통계적으로 방어되는 변화율
> 방식으로 재면 위처럼 약하다. 전 세계 M2 집계 실측은 데이터가 열리면 바로 돈다.

## 4. 그래서 시스템에 어떻게 반영하나

**세 실측이 같은 방향을 가리킨다: 거시 결합은 실재하나 국면 의존적이고 완만하다.**
이건 이미 있는 설계를 **정면으로 뒷받침한다** — 거시는 BCS 점수(방향)에 넣지
않고, **LRS(유동성 레짐 축)** 의 크기 조절(0.75~1.25배)에만 쓴다([config/strategy.yaml]
`lrs.components` 에 `global_m2_yoy`·`dxy`). "순풍일 때 조금 더, 역풍일 때 조금 덜"
정도지, 방향 신호가 아니다.

특히 M2 실측은 **왜 방향 신호로 쓰면 안 되는지**를 보여준다 — 2023 처럼
정반대로 갈 수 있기 때문이다. M2 는 지금 `manual` 입력이라, 데이터가 열리면
`fetch_macro.py` 가 그 값을 자동으로 채우도록 잇는 것이 다음 단계다.
