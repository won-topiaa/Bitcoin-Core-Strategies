# 26. 엔캐리 트레이드 ↔ 비트코인 — 검토했고 **뺐다**

2026-08-01. "엔캐리 트레이드와 엔화 강세가 비트코인과 연관이 있는지 백테스팅
해 달라"는 요청을 실측으로 실행한 기록이다. **결론: 연관 없음.** 그래서 점수에도
사이트에도 넣지 않는다 — 금(docs/25)과 똑같은 기준을 적용했다.

```bash
python3 tools/fetch_macro.py --global                      # usdjpy·jp_rate·us_rate 포함
python3 tools/macro_correlation.py --macro data/macro.csv  # [1d] 섹션이 이 판정을 재산출
```

---

## 1. 가설과 데이터

**가설(엔캐리).** 엔은 금리가 낮아 '빌려서 위험자산을 사는' 자금줄이다. 그렇다면

- 엔이 **약해질 때**(USDJPY↑) 캐리가 활발 → 비트코인 **상승**
- 엔이 **급등할 때**(캐리 청산) 위험자산 투매 → 비트코인 **급락**

즉 **USDJPY 와 BTC 는 양(+)의 상관**이어야 한다. 이게 참이면 방향이 정해진 검정이다.

| 열 | 출처 | 주기·범위 |
|---|---|---|
| `usdjpy` | FRED **DEXJPUS** (엔/달러, ↑=엔 약세) | 일간, 1971~2026-07 |
| `jp_rate` | FRED **IRSTCI01JPM156N** (일본 단기 정책금리) | 월간, ~2026-06 |
| `us_rate` | FRED **DFF** (미국 실효 연방기금금리) | 일간, ~2026-07 |

## 2. 실측 결과 — 여섯 프레임 전부 0 근처

| 검정 | ρ | 판정 |
|---|---:|---|
| 주간 로그수익률 (836주) | **−0.05** | 무상관 (부호가 가설과 **반대**) |
| 월간 로그수익률 (192개월) | **−0.05** | 무상관 |
| 일간 선행/후행 (±20일) | 최대 **\|ρ\|=0.02** | 어떤 시차에도 없음 |
| — 2010~2017 | −0.06 | |
| — 2018~2021 | −0.05 | |
| — 2022~현재(금리차 확대기) | −0.02 | "요즘은 다르다"도 아님 |
| — 2025~현재 | −0.002 | |
| **ΔVIX 통제 부분상관** | **−0.08** | 독립 설명력 없음 |
| **나스닥 통제 부분상관** | **−0.06** | 독립 설명력 없음 |

## 3. 결정적 검정 — "엔 때문"인가, "그냥 위험회피"인가

단순 상관만 보면 반박이 가능하다: *"캐리 청산은 평시가 아니라 **사건**으로 온다.
평균을 보면 당연히 안 보인다."* 그래서 **엔이 급등한 주(주간 −2.08% 이하, 하위 5%,
41주)만** 따로 봤다. 실제로 이런 주들이 있다 —

| 주 | USDJPY | BTC |
|---|---:|---:|
| 2024-W31 | −4.57% | **−15.63%** |
| 2022-W45 | −3.77% | **−24.96%** |
| 2013-W23 | −3.67% | −20.49% |

극단 사례만 보면 가설이 맞아 보인다. 그런데 **41주 전체 평균은 +1.50%** 로,
나머지 주(+1.63%)와 **차이가 −0.13%p 뿐**이다. 그래서 한 겹 더 들어가, 이 41주를
**공포(ΔVIX)가 커졌는지**로 쪼갰다:

| 엔 급등 주 | 개수 | 그 주 BTC 평균 |
|---|---:|---:|
| 공포도 함께 커진 주 | 26 | **+0.83%** |
| 공포는 잠잠한데 엔만 급등한 주 | 15 | **+2.66%** |

> **엔 급등 '자체'가 원인이라면 두 그룹 다 마이너스여야 한다. 둘 다 플러스다.**
> 게다가 공포가 없을 때는 오히려 더 올랐다. 2024-W31·2022-W45 의 폭락은 엔이
> 아니라 **그 주에 같이 터진 전반적 위험회피** 때문이다.

이것은 상관의 크기 비교와도 일치한다 — BTC 는 **ΔVIX(−0.13)·나스닥(+0.13)** 에
**엔(−0.05)보다 2~3배 강하게** 붙어 있다. 엔은 위험회피의 **대리변수**일 뿐,
비트코인에 대한 **독립 정보가 없다**.

## 4. 금리차(캐리 유인 크기)도 마찬가지

캐리의 '연료'는 미−일 금리차다. 이것도 봤다.

- 금리차 **수준** ↔ 다음달 BTC 수익률: ρ **−0.11**
- 금리차 **변화** ↔ 당월 BTC 수익률: ρ **−0.03**
- 금리차가 큰 달(캐리 유인↑) BTC 평균 **+3.06%** vs 작은 달 **+11.30%**

가설대로면 금리차가 클 때 더 올라야 하는데 **오히려 덜 올랐다.** 다만 이건
"금리차가 클 때 = 대개 미국 긴축기" 라는 교란이 섞인 값이라, 반대 방향의 증거로
쓰기보다 **"이쪽에도 쓸 만한 신호가 없다"** 로 읽는 것이 정직하다.

## 5. 그래서 어떻게 했나

**점수(BCS)에도, 실행 크기(LRS)에도, 사이트에도 넣지 않는다.** 금과 같은 기준이다 —
|ρ| < 0.2 이고 통제하면 남는 게 없는 신호는 쓰지 않는다. **중국 유동성 페이지 이름을
'매크로와의 연관성' 으로 바꾸지 않은 이유도 이것이다**: 넣을 것이 없으면 이름만 넓히는
것은 없는 내용을 있는 것처럼 보이게 한다.

다만 다른 기각 후보들처럼 **검정을 재현 가능하게 남긴다**:

| 파일 | 하는 일 |
|---|---|
| `tools/fetch_macro.py` | `usdjpy`·`jp_rate`·`us_rate` 를 FRED 에서 받아 `data/macro.csv` 에 넣는다 |
| `tools/macro_correlation.py` | `carry_analysis()` + 리포트 **[1d]** 섹션이 매번 이 판정을 재산출한다(ΔVIX 통제 포함) |
| `tests/test_macro.py` | 심은 양의 상관을 되찾는지 + **공통 원인을 통제하면 가짜 상관이 사라지는지** 검증 |

데이터가 더 쌓이거나 국면이 바뀌면 같은 명령 한 줄로 재검증된다.
