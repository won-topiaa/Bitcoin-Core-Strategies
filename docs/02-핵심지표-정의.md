# 02. 핵심지표 정의서


> **갱신 (2026-07-29).** 보유자 행동 계열은 이후 제거되어 BCS 는 3계열이 됐다.
> 가중치는 밸류에이션 40 / 가격·추세 33 / 공급·채굴 27 이다. 이 문서에서
> 그 계열을 다루는 부분은 **결정 당시의 기록**으로 남겨 둔다.
> 근거: [10 보유자 계열 제거](10-보유자-계열-제거.md).
지표 11개 + 거시 4개. 각각에 대해 **무엇을 재는지 / 어떻게 얻는지 / 어떤 값이
무슨 뜻인지 / 어디서 배신하는지**를 적었다.

앵커 좌표는 전부 `config/strategy.yaml`에 있다. 이 문서는 그 숫자를 왜 그렇게
잡았는지를 설명한다.

> **2026-07-28 갱신** — 16년치 실측으로 **상단 앵커를 전면 재조정**했다. 아래
> 표들은 조정 후 값이다. 하단(저평가) 앵커는 네 번의 사이클 저점에서 모두 정상
> 작동해 그대로 두었다. 근거는 [07 실측 검증](07-실측-검증.md).
>
> 같은 날 **서멀캡 배수**를 밸류에이션 계열에 편입했다. 이 지표만 앵커가 아니라
> 퍼센타일 전용으로 정규화된다 — 선별 근거는 [08 지표 선별](08-지표-선별.md#편입-서멀캡-배수).

## 읽는 법

**앵커**란 "원시값 → 점수" 대응표다. 예를 들어 MVRV Z-Score의 앵커에 `[3.20, 0.70]`이
있으면, Z가 3.2일 때 점수가 +0.70이라는 뜻이다. 사이 값은 선형보간하고, 표 바깥은
끝값으로 고정한다.

점수는 항상 **−1(극단 저평가) ~ 0(중립) ~ +1(극단 과열)**이다.

터미널에서 각 지표의 앵커 표를 직접 볼 수 있다.

```bash
btc-core explain mvrv_z
```

## 자동 / 수동 경계

| | 지표 | 얻는 방법 |
|---|---|---|
| **자동** | MVRV Z, NUPL, 서멀캡, Pi Cycle, GRM, 200주 배수, 2년 배수, Puell, Hash Ribbons, 중국 M2 임펄스 | CoinMetrics 커뮤니티 API + 공개 데이터로 직접 계산 (키 불필요) |
| **수동** | RHODL, Reserve Risk, LTH 배수, CVDD, 거시 3종(DXY·Fed·ETF) | BM Pro 차트를 보고 YAML에 입력 |

수동 입력이 절반 가까이 된다는 게 결함처럼 보일 수 있는데, 실제로는 그렇지 않다.
이 지표들은 **월 1~2회 확인이면 충분한 느린 지표**다. Reserve Risk가 하루 만에
초록에서 빨강으로 가는 일은 없다. 오히려 매달 한 번 직접 차트를 들여다보게 되는
쪽이 원문 6.4의 "판단을 기록한다"와 잘 맞는다.

수동 값은 45일이 지나면 경고가 뜨고, 120일이 지나면 자동으로 결측 처리된다.
석 달 전 숫자로 오늘을 판단하는 일이 조용히 벌어지지 않게 하기 위한 장치다.

# 계열 1 — 밸류에이션 (BCS 지분 30%)

집계 방식: **max_abs** — 두 지표 중 더 극단적인 쪽 하나만 채택한다.
계산 재료가 같아서 합산하면 한 번의 확인을 두 번으로 세게 되기 때문이다(원문 6.1).

## 1.1 MVRV Z-Score

**재는 것** — 시장 전체가 깔고 앉은 미실현 이익의 크기. 시가총액과 실현시총의
차이를 시가총액의 표준편차로 나눈다.

```
Z = (시가총액 − 실현시총) ÷ stdev(시가총액 전체 이력)
```

실현시총은 각 코인이 마지막으로 움직인 시점의 가격으로 평가한 총액이다.
시장 전체의 평균 매입 원가에 가깝다.

**앵커**

| Z | 점수 | 의미 |
|---:|---:|---|
| -0.50 | -1.00 | 시장 전체가 손실 — 2015/2018/2022 저점이 이 부근 |
| 0.00 | -0.75 | 평균 원가 수준 |
| 0.50 | -0.50 |  |
| 1.00 | -0.25 |  |
| 1.50 | +0.00 | 중립 |
| 2.00 | +0.30 |  |
| 2.50 | +0.55 |  |
| 3.00 | +0.75 |  |
| 3.50 | +0.90 | **2025 사이클 최대 3.35** |
| 5.00 | +1.00 | 2021 사이클 최대 7.15 는 여기서 포화 |

**왜 상단을 6으로 잘랐나** — 원문 3.2가 이렇게 말한다.

> 초기 사이클에서는 Z-Score가 7 이상까지 치솟았지만 사이클을 거듭할수록 고점
> 수치가 낮아지고 있습니다. "몇 이상이면 매도"보다는 "빨간 밴드에 진입했는가"로
> 보는 편이 현실적입니다.

과거 최고치(10 이상)에 +1.0을 걸면 앞으로 영원히 +1.0이 안 나온다. 최근 사이클
고점대(3.2)에 +0.70을 두는 쪽이 현실적이다. 여기에 더해 **퍼센타일 혼합**이
작동한다(아래 참조).

**배신하는 지점** — 실현시총은 거래소 내부 이동이나 자전거래에 오염될 수 있다.
그리고 ETF 같은 랩(wrapper) 안에서 손이 바뀌면 온체인에 안 잡힌다. 원문 7.2가
지적하는 구조 변화가 정확히 이 지점을 건드린다.

## 1.3 서멀캡 배수

**재는 것** — `시가총액 ÷ 누적 채굴 수익`. 분모는 비트코인이 만들어진 이래
채굴자에게 지급된 달러의 총합이다. "이 네트워크를 만드는 데 지금까지 얼마가
들었나" 대비 "시장이 얼마로 평가하나"를 본다.

**앵커가 없다.** 이 지표만 퍼센타일 전용이다. 분모가 단조증가하고 반감기마다
증가 속도가 느려져서 비율에 구조적 상승 추세가 있다. 사이클 저점 값이
2.11(2015) → 5.57(2018) → 6.85(2022) → 13.88(2026)로 계속 올라간다.
어떤 고정 앵커도 즉시 무의미해지므로 **4년 분포에서의 순위만** 쓴다.

과거 이력이 90일치 미만이면 결측 처리된다(`requires_history: true`).
앵커 단독으로는 의미 있는 값이 나오지 않기 때문이다.

**성격 — 고점 특화.** 4년 퍼센타일 기준 고점 평균 +0.86(전 지표 1위),
저점 평균 −0.56(꼴찌)이다. 2025-10 가격 고점에서 +0.91로, MVRV(+0.71)나
200주 배수(+0.81)보다 정확했다.

**약점이 무해한 이유** — 계열 집계가 `max_abs`라 바닥에서는 더 극단인
MVRV Z(−0.99)가 선택되고 이 지표(−0.12)는 무시된다.

**배신하는 지점** — 상승 추세가 언젠가 꺾이면(채굴 수익이 수수료 중심으로
재편되는 등) 퍼센타일의 의미도 바뀐다. 그리고 MVRV와의 상관이 +0.77이라
완전히 독립적인 확인은 아니다.

## 1.2 NUPL

**재는 것** — 같은 재료로 만든 비율판.

```
NUPL = (시가총액 − 실현시총) ÷ 시가총액
```

시가총액의 몇 %가 미실현 이익인가.

**앵커** — 원문 3.4의 심리 단계 경계를 그대로 썼다.

| NUPL | 점수 | 의미 |
|---:|---:|---|
| -0.25 | -1.00 | 항복 (Capitulation) |
| 0.00 | -0.75 | 손익분기 |
| 0.15 | -0.45 |  |
| 0.25 | -0.28 |  |
| 0.35 | +0.00 | 낙관 |
| 0.45 | +0.30 |  |
| 0.55 | +0.60 | 확신 |
| 0.62 | +0.80 |  |
| 0.70 | +0.92 | **2025 사이클 최대 0.64** |
| 0.80 | +1.00 | 도취 (Euphoria) — 2013 최대 0.83 |

**MVRV Z와의 관계** — 분자가 같고 분모만 다르다(표준편차 vs 시가총액). 방향은
거의 항상 같이 움직인다. 그래서 계열 안에서 하나만 채택한다. NUPL의 단계 이름은
점수에 안 쓰이지만 출력에는 남는다. "지금 확신 구간"이라는 말이 "+0.55"보다
상황을 잘 설명할 때가 있다.

# 계열 2 — 보유자 행동 (BCS 지분 25%)

집계 방식: **평균**. 세 지표가 각각 다른 각도에서 같은 질문에 답한다.

## 2.1 RHODL Ratio — 밴드 위치로 입력

**재는 것** — 1주일 미만 보유 코인의 실현가치 대비 1~2년 보유 코인의 실현가치.
여기에 시장의 나이를 곱해 보정한다. 값이 커지면 오래된 코인이 새 자금으로
대거 넘어가고 있다는 뜻이다.

**입력 방법이 다르다.** 이 지표만 원시값이 아니라 **밴드 위치 0~1**로 넣는다.

- `0.0` = 하단 초록 밴드 바닥
- `0.5` = 중간
- `1.0` = 상단 빨간 밴드

이유는 정직하게 말해서, RHODL의 절대 수치는 사이클마다 자릿수가 달라지고 무료로
확인할 방법이 없어서 신뢰할 만한 앵커를 세울 수 없기 때문이다. BM Pro의 차트는
로그 스케일에 색 밴드가 그려져 있고, 실전에서 우리가 읽는 정보도 결국 "지금 위아래
밴드 사이 어디쯤인가"다. 그 판단을 그대로 숫자로 받는 편이 가짜 정밀도보다 낫다.

**앵커**

| 밴드 위치 | 점수 |
|---:|---:|
| 0.00 | −1.00 |
| 0.15 | −0.70 |
| 0.35 | −0.25 |
| 0.50 | 0.00 |
| 0.70 | +0.40 |
| 0.85 | +0.75 |
| 1.00 | +1.00 |

**배신하는 지점** — 눈대중이라 주관이 들어간다. 같은 차트를 두 번 봐도 0.45와
0.55가 갈릴 수 있다. 그래서 이 지표 하나의 최종 지분은 8.3%로 묶여 있다.
0.1의 오차가 최종 BCS를 바꾸는 폭은 1점 미만이다.

## 2.2 Reserve Risk

**재는 것** — 장기 보유자가 팔지 않고 버티며 포기한 기회비용의 누적(HODL Bank)으로
현재 가격을 나눈 값.

- **낮다** = 가격은 싼데 장기 보유자의 확신은 강하다 → 위험 대비 보상 유리
- **높다** = 가격은 비싼데 확신은 약해졌다 → 불리

**앵커**

| Reserve Risk | 점수 |
|---:|---:|
| 0.0008 | −1.00 |
| 0.0015 | −0.70 |
| 0.0025 | −0.35 |
| 0.0040 | 0.00 |
| 0.0060 | +0.40 |
| 0.0100 | +0.75 |
| 0.0200 | +1.00 |

원문 3.5의 초록(<0.002)·빨강(>0.02) 기준을 바탕으로 하되, 최근 사이클 고점이
그보다 낮게 나오는 경향을 반영해 중간 구간을 촘촘히 했다.

**이 지표의 특별한 가치** — 원문 3.5의 표현대로 "가격만 보는 지표들과 계산 원리가
완전히 다르다". 가격이 오르면 분모가 커져 값이 오르지만, 동시에 장기 보유자가
버티면 분자도 커져 값이 눌린다. 가격 상승과 보유자 확신이 함께 가는 국면과,
가격만 오르는 국면을 구분해 준다. 4계열 중 가장 대체 불가능한 지표다.

**재는 것** — `현재가 ÷ LTH 실현가격`. LTH 실현가격은 155일 이상 움직이지 않은
코인들의 평균 매입가다.

**앵커**

| 배수 | 점수 | 의미 |
|---:|---:|---|
| 0.70 | −1.00 | 장기 보유자가 30% 손실 — 역사적으로 극히 드물다 |
| 0.90 | −0.70 | |
| 1.10 | −0.35 | 장기 보유자 원가 부근 |
| 1.50 | 0.00 | 중립 |
| 2.20 | +0.40 | |
| 3.00 | +0.75 | |
| 3.50 | +1.00 | 원가 대비 3.5배 — 익절 압력 최대 |

원문 4.5는 이렇게 정리한다.

> 약세장에서 이 선은 강한 지지선 역할을 하며, 가격이 이 선 아래로 내려간 시기는
> 역사적으로 매우 드물고 짧았습니다.

그래서 배수 1.0 부근이 강한 저평가 신호가 되도록 앵커를 잡았다.

# 계열 3 — 가격·추세 극단 (BCS 지분 25%)

집계 방식: **평균**. 네 지표가 같은 아이디어의 변형이므로 합산하지 않는다.
가격 시계열만 있으면 전부 자동 계산된다.

## 3.1 Pi Cycle 근접도

```
비율 = 111일 이동평균 ÷ (350일 이동평균 × 2)
```

1.0 도달이 곧 Pi Cycle Top 교차다.

| 비율 | 점수 | 의미 |
|---:|---:|---|
| 0.50 | -1.00 | 가격이 평평하면 정확히 이 값 — 약세장 상시 |
| 0.56 | -0.55 |  |
| 0.62 | -0.20 |  |
| 0.68 | +0.20 |  |
| 0.74 | +0.55 | **2025 사이클 최대 — 교차 실패** |
| 0.85 | +0.85 |  |
| 1.00 | +1.00 | 교차. 2021 이후 도달 없음 |

가격이 완전히 평평하면 111일선 = 350일선이므로 비율은 정확히 0.5다. 이것이
"아무 일도 안 일어나는" 기준점이고, 앵커의 −1.00이 여기 걸려 있다는 건 약세장에서
이 지표가 항상 바닥값을 낸다는 뜻이다. 고점 탐지에는 유용하지만 **저점 판단에는
정보가 없다.** 그래서 계열 평균에 묻히도록 설계했다.

**주의** — 원문 3.1의 경고를 다시 옮긴다.

> 단독 신호로 전량 매도하는 근거로 쓰기보다는, 다른 지표와 함께 볼 경보음 정도로
> 다루는 편이 안전합니다.

이 시스템에서 Pi Cycle의 최종 지분은 6.25%다. 교차가 발생해도 BCS는 최대 6점
남짓 움직인다. 밴드 하나를 넘기려면 다른 계열이 함께 움직여야 한다.

# 계열 4 — 공급·채굴 (BCS 지분 20%)

집계 방식: **평균**.

## 4.1 Puell Multiple

```
Puell = (일간 신규 발행량 × 가격) ÷ 그 값의 365일 이동평균
```

오늘 채굴자들이 버는 돈이 지난 1년 평균의 몇 배인가.

| Puell | 점수 | 의미 |
|---:|---:|---|
| 0.30 | -1.00 | 2015 저점 0.31 |
| 0.50 | -0.75 |  |
| 0.80 | -0.35 |  |

| 1.40 | +0.25 |  |
| 1.75 | +0.50 |  |
| 2.10 | +0.72 |  |
| 2.45 | +0.90 | **2025 사이클 최대 2.43** |

원문 3.6이 짚듯 "공급 측면에서 접근하는 몇 안 되는 지표"다. 수요 기반 지표들이
전부 같은 방향을 가리킬 때 Puell이 따라오는지가 중요한 확인이 된다.

**반감기 직후 왜곡** — 반감기가 지나면 발행량이 절반이 되므로 Puell이 급락한다.
365일 평균이 새 발행량에 적응하는 데 1년이 걸린다. 반감기 후 6~12개월 동안은
이 지표가 실제보다 낮게 나온다는 걸 알고 봐야 한다.

## 4.2 Hash Ribbons — 상태 기계

연속값이 아니라 상태다. 해시레이트 30일선과 60일선의 관계로 판정한다.

| 상태 | 조건 | 점수 |
|---|---|---:|
| `recovery` | 30일선이 60일선을 재돌파한 뒤 45일 이내 | **−1.00** |
| `capitulation` | 30일선 < 60일선 | −0.55 |
| `normal` | 그 외 | 0.00 |
| `expansion` | 30일선이 60일선을 8% 이상 초과 | +0.30 |

**왜 항복이 −0.55이고 회복이 −1.00인가** — 원문 4.4의 핵심이 여기 있다.

> 이후 30일선이 다시 60일선 위로 올라오면서 가격도 상승하기 시작하면 매수 신호로
> 봅니다.

신호는 항복 **자체**가 아니라 항복의 **끝**이다. 항복이 진행 중일 때는 아직
더 떨어질 수 있다. 그래서 항복 구간에는 중간 점수를 주고, 재돌파가 확인되면
최대 매수 점수를 준다. Charles Edwards의 말대로 "채굴자가 포기할 때가 아마도
역사상 가장 강력한 비트코인 매수 신호"라면, 정확히는 **포기가 끝날 때**다.

# 퍼센타일 혼합 — 앵커의 노후화에 대한 보험

고정 앵커에는 구조적 문제가 있다. 원문 7.3이 짚는 그대로다.

> 위 지표들의 밴드와 임계값은 대부분 과거 데이터에 맞춰 설정된 것입니다.

사이클마다 고점 수치가 낮아지면, 오늘 잘 맞는 앵커가 다음 사이클엔 안 맞는다.

그래서 **과거 4년 분포에서의 퍼센타일**을 함께 계산해 섞는다.

```
최종 점수 = 고정 앵커 점수 × 0.65  +  퍼센타일 점수 × 0.35
```

퍼센타일은 절대 수치를 안 본다. "지난 4년 중 지금이 상위 몇 %인가"만 본다.
그래서 고점 수치가 전체적으로 낮아져도 상대적 극단은 계속 잡아낸다.

혼합 비율은 `--adaptive-weight`로 조정할 수 있다. `0.0`이면 고정 앵커만 쓴다.

**두 척도가 크게 갈리면 경고가 뜬다.** 차이가 0.45를 넘으면 리포트에 이렇게 나온다.

```
! MVRV Z-Score: 고정 앵커(+0.32)와 과거분포(+1.00)가 크게 갈립니다 — 앵커 재조정 검토
```

이건 버그가 아니라 정보다. "절대 기준으로는 평범한데 최근 4년 기준으로는 최고치"라는
뜻이고, 보통 앵커가 현실을 못 따라가고 있다는 신호다.

현재 이 혼합은 **MVRV Z와 Puell에만** 적용된다. 두 지표만 자동 계산 과정에서
4년치 이력이 함께 만들어지기 때문이다. 다른 지표에도 적용하려면 과거값을 따로
쌓아야 한다.
