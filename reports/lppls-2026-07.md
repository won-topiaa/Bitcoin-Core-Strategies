## 5. 방향 정확도 8/8 은 공짜다

**무료 기준선과 비교하지 않으면 어떤 지표든 좋아 보인다.** 기준선은 한 줄이다 —
"최근 1년 수익률이 양수면 고점, 음수면 저점".

| 국면 | 날짜 | 최근 1년 | 기준선(한 줄) | LPPLS(7 파라미터) |
|---|---|---:|---|---|
| 고점 | 2013-11-30 | +8793% | 고점 ✓ | 고점 ✓ |
| 고점 | 2017-12-17 | +2338% | 고점 ✓ | 고점 ✓ |
| 고점 | 2021-11-10 | +323% | 고점 ✓ | 고점 ✓ |
| 고점 | 2025-10-06 | +99% | 고점 ✓ | 고점 ✓ |
| 저점 | 2015-01-14 | −78% | 저점 ✓ | 저점 ✓ |
| 저점 | 2018-12-15 | −82% | 저점 ✓ | 저점 ✓ |
| 저점 | 2022-11-21 | −73% | 저점 ✓ | 저점 ✓ |
| 저점 | 2026-06-06 | −42% | 저점 ✓ | 저점 ✓ |

**둘 다 8/8 이다.** 파라미터 7개, 격자 1,320점, 계산 10분이 한 줄짜리 계산과
같은 답을 낸다. LPPLS 의 방향 판정은 새 정보가 아니라 **최근 추세의 재포장**이다.

돌이켜보면 당연하다. 고점 근처에서는 가격이 올라온 상태이므로 위로 발산하는
적합만 맞고, 바닥 근처에서는 그 반대다. 방향은 데이터에 이미 적혀 있다.

## 6. 판정 — 기각 (표시 전용으로도)

| 관문 | 결과 |
|---|---|
| 방향 정확도 | 8/8 — 하지만 **무료 기준선도 8/8** |
| 한 임계로 네 사이클 일관 | **불가** — 고점에서 달성 가능한 최소 오차가 0.09~0.32 로 3.5배 차이 |
| 기저율 대비 포착 | 양의 거품 **발화 44% 인데 고점 2/4** — 기저율이 포착률보다 높다 |
| 음의 거품 | 발화 20%, 바닥 4/4, 발화 구간 5개 전부 이후 수익 양수 — **여기만 유효** |
| 새 정보 | 바닥은 기존 시스템이 이미 가장 확실한 구간(구간 폭 2.4~4.4) |
| 비용 | 파라미터 7개 + 격자 1,320점 + 계산 10분 |

**편입하지 않는다.** 근거는 셋이다.

1. **약속했던 장점이 데이터에서 사라진다.** LPPLS 를 후보로 올린 이유는
   "진폭이 아니라 진동수를 읽으므로 진폭 감쇠에 면역"이었다. 그런데 감쇠는
   **적합 품질의 저하로 되돌아온다** — 네 고점에서 달성 가능한 최소 오차가
   0.317 / 0.119 / 0.220 / 0.091 이다. 한 임계로 네 사이클을 일관되게 다룰
   수 없다는 점에서 Puell·Pi Cycle 과 같은 실패다.

2. **양의 거품 쪽은 기저율에 진다.** 임계 15%에서 245개 지점 중 108개(44%)가
   발화하는데 고점은 2/4 밖에 못 잡는다. 발화 구간을 보면 이유가 보인다 —
   2015-11 ~ 2018-01 이 **한 덩어리로 38개 지점**, 2023-11 ~ 2026-01 이 또
   38개다. "거품이 곧 터진다"가 아니라 "가격이 오르는 중"을 재고 있다.

3. **음의 거품 쪽은 유효하지만 새 정보가 아니다.** 바닥 4/4, 발화 구간 5개
   전부 이후 수익이 양수 — 이건 진짜다. 그런데 **바닥은 기존 시스템이 이미
   가장 확실한 구간**이다(전환점 구간 폭이 저점에서 2.4~4.4, 고점에서
   12.2~19.4). 잘하는 곳을 더 잘하게 만드는 지표는 우선순위가 낮다.

### 그래도 남길 것

계산 코드는 `tools/lppls.py` 에 남긴다. 표준 라이브러리만으로 도는
LPPLS 구현이 흔치 않고, **다음에 누군가 "LPPLS 를 넣어 보자"고 할 때 이
표가 같은 실험을 반복하지 않게 해 준다.**

한 가지는 확인됐다 — 이 시스템이 고점을 잘 못 잡는 것은 지표 선택의 문제가
아니다. **2013년과 2025년 고점은 구조 자체가 다르다.** 같은 모형으로
설명하려 하면 오차가 3.5배 벌어진다. 그건 지표를 바꿔서 해결할 문제가 아니다.
